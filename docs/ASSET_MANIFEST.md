# MESME source asset manifest

**Collected 19 November 2026 · Dubai time**

The user confirmed MESME owner permission to reuse existing website assets and requested committing them to the project repository. The archive under `assets/source/` contains 30 source files totalling 6,996,736 bytes, plus three upstream font notices. It preserves the available public web versions and original filenames. Production derivatives should be created separately. [Homepage](https://mesmeofficial.com/)

The inventory covers the MESME wordmark, four site icons, two product renders, ten editorial images and posters, two hero films, and ten font files. All 30 requests returned HTTP 200. Checks verified the byte counts and hashes, decoded the raster images and a frame from each MP4, parsed the SVG, and checked WOFF2 headers and declared file lengths. The browser's mobile hero source is an almost square video. Check the crop when using it in a portrait layout.

The homepage font declarations use HTTP. The source links below use the HTTPS endpoints from which the files were saved. Family and weights are taken from the page declarations.
